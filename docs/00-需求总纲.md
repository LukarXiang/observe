**版本 V2.0 · 2026-09-28**。取代 `archive/quant_research_requirements_v1.0_zh.md`（V1.0 保留作来源，不再维护）。

## 一、一句话

在本机搭一个自己用的 A 股选股研究工作台：免费数据自动入库 → 因子 → 机器学习 → 选股 → 按 A 股规则回测 → 评价，全程可复现；
带一个本机网页界面，用来看数据、看结果、提交任务、追查异常。

## 三、范围

### 第一版要做

1. **数据底座**：交易日历、证券主数据、全市场日线（原始价 + 复权因子 + 停牌 + ST）、公司行动、指数日线的全量初始化与每日增量；
   质量审计；数据快照。
2. **回测账本**：A 股沪深主板规则（T+1、整手、涨跌停、分红送转配股、按日期生效的税费），手算用例全部通过。
3. **日频研究闭环**：股票池、约 30 个量价因子、统一标签、滚动切分、单因子评价、四个模型（两个基线 + Ridge + LightGBM）、
   Top-N 等权组合、回测、三层评价、实验记录与离线复现。
4. **5 分钟数据**：分钟股票池 2020 年起的 5 分钟线（只用 BaoStock，决策 16），分钟聚合特征，
   「加不加分钟特征」的成对对照实验。
5. **本机网页界面**：数据中心、证券浏览、因子实验室、实验（列表 / 详情 / 对比）、任务队列。
6. **命令行**：与网页界面功能对等。

### 第一版不做

实盘交易与券商接口、做空与融资融券、多用户与登录、分布式计算、高频撮合与盘口模拟、完整逐笔（Level-2）研究、
强化学习与深度学习、大语言模型自动研究、盘中实时信号。

### 按需扩展（第一版完成后，一次只开一个）

2020 年以前的 5 分钟线（通达信逐笔合成，缺退市股）、近期 1 分钟数据归档、盘中行情快照、公式自动搜索（gplearn）、组合优化（skfolio）、创业板 / 科创板 / 北交所规则、财务因子。

## 四、不能破的规则

这些规则跨模块生效，违反任何一条的结果都不算数：

1. **时间**：因子只用决策时点已知的数据；标签成熟之前不进训练；信号在收盘后形成，最早下一交易日开盘成交。
2. **价格**：因子和标签用后复权价；下单、成交、费用、资金账只用原始价。
3. **股票池**：用当时在市的证券，不用今天的列表倒推；不提前剔除以后会退市、停牌的股票。
4. **账本**：全项目只有一套资金账；每日净值恒等式成立；无法处理的情况阻断正式评价，不删持仓、不猜结果。
5. **数据**：缺数据不是没有信号，抓取失败不是证券不存在，零值占位不是有效价格；不无条件补零、不用未来值回填。
6. **复现**：一次实验固定数据快照、股票池、因子、标签、切分、模型、交易规则；旧实验不被覆盖；离线可重跑。
7. **诚实**：「代码已实现」「测试已通过」「真实数据已验证」「研究证据充分」是四个不同状态，分开报告。没有正收益也能完成软件验收。

## 五、模块地图

组合构建与回测账本在执行时合并为一个“组合与账本循环”：预测分数可提前冻结，订单必须在每日收盘决策阶段依据真实持仓和现金生成，并于下一交易日开盘按先卖后买执行；非调仓日按目标名单补单。

```
          ┌──────── 数据层 10 ─────────┐
免费接口 → │ 原始记录 → 标准表 → 快照    │
外部文件 → │ 审计                       │
          └────────────┬──────────────┘
                       ↓
      股票池 11 → 因子 12 → 标签与切分 13 → 模型 14 → 预测分数
                                                     ↓
                                   组合构建 15 → 订单意图 → 回测账本 16
                                                              ↓
                                               评价与报告 17 ← 实验管理 18
                                                              ↓
                               后端服务 19（命令行 + Web 接口 + 任务队列）
                                                              ↓
                                                     前端界面 20
```
