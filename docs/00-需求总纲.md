# observe · 个人 A 股量化研究平台 · 需求总纲

**版本 V2.0 · 2026-09-28**。取代 `archive/quant_research_requirements_v1.0_zh.md`（V1.0 保留作来源，不再维护）。

本文件是需求的入口：说清**做什么、不做什么、按什么顺序做、做到什么算完**。每个模块的细节在 `modules/` 下各自一篇；
所有做过的取舍在 `02-决策记录.md`；数据源的实测事实在 `01-数据源实测报告.md`；名词以仓库根目录 `CONTEXT.md` 为准。

## 一、一句话

在本机搭一个自己用的 A 股选股研究工作台：免费数据自动入库 → 因子 → 机器学习 → 选股 → 按 A 股规则回测 → 评价，全程可复现；
带一个本机网页界面，用来看数据、看结果、提交任务、追查异常。

## 三、范围

### 第一版要做

1. **数据底座**：交易日历、证券主数据、全市场日线（原始价 + 复权因子 + 停牌 + ST）、公司行动、指数日线的全量初始化与每日增量；
   质量审计；数据快照。
2. **回测账本**：A 股沪深主板规则（T+1、整手、涨跌停、分红送转配股、按日期生效的税费），手算用例全部通过。
3. **日频研究闭环**：股票池、约 30 个量价因子、统一标签、滚动切分、单因子评价、四个模型（两个基线 + Ridge + LightGBM）、
   Top-N 等权组合、回测、三层评价、实验记录与离线复现。
4. **5 分钟数据**：研究股票池的 5 分钟线（2020 年起用 BaoStock，2020 年以前用通达信逐笔自行合成），分钟聚合特征，
   「加不加分钟特征」的成对对照实验。
5. **本机网页界面**：数据中心、证券浏览、因子实验室、实验（列表 / 详情 / 对比）、任务队列。
6. **命令行**：与网页界面功能对等。

### 第一版不做

实盘交易与券商接口、做空与融资融券、多用户与登录、分布式计算、高频撮合与盘口模拟、完整逐笔（Level-2）研究、
强化学习与深度学习、大语言模型自动研究、盘中实时信号。

### 按需扩展（第一版完成后，一次只开一个）

近期 1 分钟数据归档、盘中行情快照、公式自动搜索（gplearn）、组合优化（skfolio）、创业板 / 科创板 / 北交所规则、财务因子。

## 四、不能破的规则

这些规则跨模块生效，违反任何一条的结果都不算数：

1. **时间**：因子只用决策时点已知的数据；标签成熟之前不进训练；信号在收盘后形成，最早下一交易日开盘成交。
2. **价格**：因子和标签用后复权价；下单、成交、费用、资金账只用原始价。
3. **股票池**：用当时在市的证券，不用今天的列表倒推；不提前剔除以后会退市、停牌的股票。
4. **账本**：全项目只有一套资金账；每日净值恒等式成立；无法处理的情况阻断正式评价，不删持仓、不猜结果。
5. **数据**：缺数据不是没有信号，抓取失败不是证券不存在，零值占位不是有效价格；不无条件补零、不用未来值回填。
6. **复现**：一次实验固定数据快照、股票池、因子、标签、切分、模型、交易规则；旧实验不被覆盖；离线可重跑。
7. **诚实**：「代码已实现」「测试已通过」「真实数据已验证」「研究证据充分」是四个不同状态，分开报告。没有正收益也能完成软件验收。

## 七、分阶段计划

每个阶段结束都要：测试全绿、提交一次、写明「做了什么 / 实际跑了哪些测试 / 哪些真实数据已验证 / 还有什么限制」。
**前一阶段验收通过才开始下一阶段。**

### 阶段 0：数据源实测与需求拆解（本次，已完成）

交付：三个数据源的探测脚本与结果、`01-数据源实测报告.md`、本文件及全部模块文档、决策记录、技术选型、参考项目借鉴、`D:\envs\quant` 环境。

### 阶段 1：数据底座

内容：包骨架与配置；无代理请求会话；BaoStock / 新浪 / 腾讯 / 通达信适配器；交易日历；证券主数据；
全市场日线全量初始化（默认从 2005-01-04 起）与每日增量；复权因子；公司行动；指数日线；质量审计；数据快照；
后端最小接口与任务队列；前端「数据中心」「证券浏览（日线）」「任务」三页。

验收：
- 覆盖报告：每个交易日的在市证券数与 BaoStock 当日证券清单一致（不一致的日子全部列出原因）；
- 交叉核对：随机抽 200 个「证券 × 交易日」，BaoStock 日线的开高低收与新浪逐项一致率；不一致的逐条列出；
- 复权因子与公司行动相互推算一致（抽样 50 只）；
- 同一分区重复下载不产生重复行；下载中断后重跑，已提交的分区不变、进度不越过失败分区；
- 冻结一个快照，删掉缓存后按快照重读，内容指纹一致。

### 阶段 2：回测账本

内容：沪深主板执行规则集（2005 年至今，每条带来源并标「已核实」）；账本引擎；`modules/16-回测账本.md` 的 14 个合成用例。

验收：14 个用例全部通过；至少一个用例的全部现金流由人工独立计算并逐笔一致；规则集覆盖区间内没有「查不到规则」的日子。

### 阶段 3：日频研究闭环

内容：股票池、第一批因子、标签、切分、四个模型、组合构建、评价、实验管理与复现；前端「因子实验室」「实验」页。

验收：
- 用真实数据跑通一次完整实验（默认研究区间 2007 年至今），三层报告齐全；
- `observe reproduce` 离线重跑，因子、标签、订单、账本逐值一致；
- 换选股参数跑变体，不触发重新训练；
- 模块文档里列出的测试要点全部有对应测试。

### 阶段 4：5 分钟数据与分钟特征

内容：研究股票池的 5 分钟线下载（2020 年起 BaoStock；2020 年以前通达信逐笔合成，只覆盖当时仍可查到的证券）；
合成数据与 BaoStock 在 2020 年后重叠段的逐根比对；分钟聚合特征；「日频基础因子」对「日频 + 分钟特征」的成对实验。

验收：分钟覆盖报告（按年、按证券的覆盖率，退市证券缺失单独列出）；重叠段比对一致率；成对实验报告（没有增量也照实报告）。

### 阶段 5：按需扩展

每次只选一个方向，先写明要回答的问题、看什么指标判断有无增量、工作量上限、停止条件，再开始。
