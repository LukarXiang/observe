# 分钟特征成对对照实验报告

问题：在同一个分钟股票池、同一区间、同一切分上，日频基础因子加入分钟聚合因子后，样本外预测有没有增量。设计与判断口径在看到结果之前就已固定（决策 21、`configs/research/paired_intraday_v1.yaml`）。
证据级别：**探索**（受限样本：缺退市证券的分钟数据；测试窗很少）。

## 结论

1. **没有可确认的增量。** 主实验里 Ridge 的测试窗秩 IC 从 0.0720 升到 0.0785（+0.0065），块抽样 95% 区间 [−0.0091, +0.0234] 包含 0；等权合成同样（+0.0062，区间包含 0）。
2. 事先约定的敏感性实验（训练窗缩到 252 天，测试窗从 3 个增加到 7 个）方向相反：Ridge 从 0.0609 降到 0.0526（−0.0084，区间 [−0.0173, −0.0002] 刚好不含 0），等权合成 −0.0022（区间包含 0）。两个实验合起来看，分钟因子对预测排序没有稳定的正贡献；Ridge 在训练窗较短时更差，可能是「特征多、样本少」的过拟合（未检验），不能解读为分钟因子有害。
3. 单独看，分钟因子本身有信号（7 个里 6 个的开发区间秩 IC 方向与事先假设一致，`rv_20` 与 `rskew_20` 最强），但这些信号大部分与已有因子重叠：`rsj_20` 与 `rskew_20` 的日均秩相关 0.93（3 个窗口都被去重丢弃）；`rv_20` 与 `range_20` 为 0.91，窗口 0 里 `rv_20` 被丢弃，窗口 1、2 里反而是 `range_20`（与 `vol_20` 相关 0.90）被丢弃。
4. 账本回测（成本后）的差异不能当作增量证据，见下文「组合层」：两个实验的组合层方向互相矛盾，且受少数个股主导。

## 样本与覆盖（受限样本）

分钟线覆盖研究候选行的 **99.02%**（885,044 / 893,836）；按年 98.3%（2022）、98.5%（2023）、99.1%（2024）、99.6%（2025）、99.9%（2026）。
覆盖到的行里，开盘 / 尾盘窗口都完整，没有不足 44 根的日子；只有 1,157 个证券日全天价格不变（一字板），偏度与涨跌波动比无定义。

1526 只候选证券里有 **25 只从未有分钟数据**，全部在 2023-03 至 2026-03 之间退市或被吸收合并（证券表里有退市日期），约一半是 ST / *ST：例如 `600811.SH`（*ST 东方，2025-04-30）、`000961.SZ`（ST 中南，2024-07-11）、`601989.SH`（中国重工，被吸收合并，2025-09-05）。外部分钟文件不含它们。
它们的行留在两侧，分钟因子缺失、按 0 处理（决策 21）；因此加分钟一侧对这些证券没有分钟信息。这是「受限样本：缺退市证券的分钟数据」的具体含义，实验状态因此恒为 `success_limited`。
对结论方向的影响：这些证券是样本里最差的一批标签，分钟特征本可能帮助识别它们，缺失使加分钟一侧的收益被**低估**；同时这里没有借用任何退市信息（缺失只因为文件缺，不因为事后知道退市）。

## 组合层（成本后账本回测，前 20 只，5 日调仓，初始资金 100 万）

- **等权合成，主实验**：基础侧总收益 23.0%、夏普 1.27、最大回撤 −12.5%；加分钟侧 27.9%、1.38、−12.6%；换手相同（双边日均 0.108 对 0.105）。日收益差 +0.023%，区间 [−0.045%, +0.087%] 包含 0，3 个窗口都是加分钟更高。
- **等权合成，敏感性**：基础侧总收益 3.7%、夏普 0.20；加分钟侧 32.2%、0.75；日收益差 +0.056%，区间 [+0.007%, +0.111%]，7 个窗口里 6 个更高。方向与同一实验的秩 IC 差（−0.0022）矛盾，前 20 名标签差 +0.0005 也包含 0，说明这个差异来自前 20 名个股的偶然，不当作增量证据。
- **Ridge，两个实验的基础侧回测都被账本阻断**：基础侧组合持有了后来退市的证券（主实验 `600811.SH` 自 2025-05-06 起，敏感性 `000961.SZ` 自 2024-07-12 起），账本按既定契约（持仓证券退市即阻断）不给净值。这两只证券都在「从未有分钟数据」的 25 只之内。成对比较因此只取阻断日之前双方都干净的区间：主实验 173 天，基础 +5.4%、加分钟 +15.3%，日收益差区间包含 0；窗口 2（只剩 48 天）基础 −13.1%、加分钟 +3.6%，基础侧的回撤主要来自那只退市股。这不是分钟特征的贡献——加分钟侧没有持有它，只是因为两侧的模型打分不同。敏感性实验里清洁区间 231 天，两侧都亏（−18.6% 对 −20.6%）。

组合层的结论：无法从中得到分钟特征的增量；它反映的是前 20 名个股的集中风险与退市股的处理限制。

## 限制与未解决

- 测试窗少：主实验只有 3 个窗、189 个测试日，区间宽；敏感性 7 个窗、441 天。区间包含 0 时只能说「没有可确认的增量」，不能说「确认没有」。
- 多次比较：3 个模型 × 2 组切分 × 秩 IC / 前 20 名 / 组合共十几个比较，没有做多重比较校正；敏感性里 Ridge 区间上界 −0.0002 刚好不含 0，应当当作弱证据。
- 受限样本：25 只候选证券（全部是区间内退市或被吸收合并的证券）从未有分钟数据，加分钟侧对它们是「中性」；组合层里退市股的处理（账本阻断）使 Ridge 的成本后比较不完整。账本对持仓退市的估值仍未支持，是阶段 3 遗留事项。
- 区间只有 2022 年之后；分钟线来源单一（外部 1 分钟文件合成，与 BaoStock 5 分钟线的分根成交量差约 1%），没有交叉核对来源的特征稳定性。
- 只做了一个分钟因子集（7 个 20 日均值）。没有检验：仅分钟因子的模型、不同窗口长度、LightGBM。
