# 模块：前端界面（web）

## 定位

本机自用的研究工作台，用来**看数据、看结果、提交任务、追查异常**。所有计算都在后端完成，前端不做任何金融计算（不算收益、不算指标），只渲染后端给的数据。

技术：Vite + React + TypeScript + ECharts，版本见 `../03-技术选型与版本.md`。代码放仓库的 `web/` 目录。

## 通用约定

- **红涨绿跌**（A 股习惯），K 线、收益、涨跌幅统一。
- 数字：收益和比例显示为百分比，保留 2 位小数；金额显示元，千分位；缺失显示「—」并可悬停看原因。
- 每个结果页顶部固定一条「口径条」：数据快照编号、区间、股票池、标签、成交时点、费用假设、证据级别。
- 所有表格可按列排序、可导出 CSV。
- 长任务提交后跳转到任务页看实时日志，不在原页面转圈等待。

## 页面

### 1. 数据中心

- **覆盖热力图**：纵轴为数据表（日线、5 分钟线、公司行动、证券清单），横轴为年份，颜色表示覆盖率；点格子看该年按板块的明细和缺失证券清单。
- **数据源状态**：各上游最近一次成功更新的时间、最新数据日期、最近 7 天的请求失败率。
- **审计问题列表**：按严重程度排列（如「某日全市场缺数据」「开盘价为 0」「复权因子与公司行动不一致」），可筛选、可跳转到对应证券。
- 按钮：发起增量更新、发起审计、冻结数据快照（都提交为任务）。

### 2. 证券浏览

- 搜索证券 → K 线图（日线 / 5 分钟线切换，原始价 / 复权价切换），下方成交量。
- K 线上标注：除权除息、送转、停牌区间、ST 区间。
- 侧栏：证券基本信息、公司行动表、在各实验中的持仓与成交记录（从这里能直接跳到那一天的账本）。

### 3. 因子实验室

- **因子列表**：注册表中的全部因子，显示公式、回看天数、最近一次评价的秩 IC 均值与覆盖率。
- **新建因子**：输入表达式 → 即时校验（语法、白名单、推算回看天数与依赖字段）→ 保存 → 提交评价任务。
- **因子评价页**：每日秩 IC 柱状图与 60 日滚动均值、按年分段表、5 组分组收益柱状图、分组换手、排名自相关、与已有因子的相似度矩阵。

### 4. 实验

- **实验列表**：名称、状态、证据级别、快照、创建时间、核心指标（年化、最大回撤、夏普、秩 IC）；可多选进入对比。
- **实验详情**（四个标签页）：
  - 概览：口径条、三层指标卡片、限制与未解决事项；
  - 组合：净值与基准曲线、回撤曲线、每日现金占比、月度收益表；
  - 账本：按日期浏览持仓；订单表（含拒单原因筛选）；成交表；**点击净值曲线上任一天 → 当天的订单、成交、持仓变化与现金流水**，用于追查「异常收益来自哪一天、哪只股票、哪笔成交」；
  - 模型：各测试窗的秩 IC、与基线的成对比较、特征重要性。
- **换组合规则**：在实验详情里改 Top-N、调仓间隔、缓冲 → 提交「组合变体」任务，结果作为该实验的变体列出。
- **对比页**：两个实验（或变体）的净值叠加、指标差值表、按年分段胜负。

### 5. 任务

任务队列：状态、类型、参数、耗时；点开看实时日志；可取消排队中的任务。

## 第一版不做

登录与权限、多人协作、移动端适配、界面上直接编辑 YAML 配置（配置文件仍在编辑器里改，界面只提交「用哪个配置文件」）、实时行情。

## 分阶段上线

| 阶段 | 上线的页面 |
| --- | --- |
| 阶段一（数据底座） | 数据中心、证券浏览（日线）、任务 |
| 阶段三（日频闭环） | 因子实验室、实验（列表、详情、对比） |
| 阶段四（分钟数据） | 证券浏览加 5 分钟线；数据中心加分钟覆盖 |
