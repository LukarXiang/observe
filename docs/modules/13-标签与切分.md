# 模块：标签与切分（labels / split）

## 职责

1. 按统一口径计算未来收益标签及其成熟时刻；
2. 生成全项目共用的时间切分计划；
3. 从因子和标签组装训练视图与推理视图。

因子评价和模型训练读的是**同一份标签**，不各自计算未来收益。

## 标签

**定义**（第一版唯一的标签，名为 `adj_open_to_open_h`）：决策日为交易日序号 k，在 k+1 日开盘买入，在 k+1+h 日开盘卖出，价格使用后复权开盘价。

```
y(k, h) = open_adj[k+1+h] / open_adj[k+1] - 1
```

用后复权开盘价计算，分红送转已体现在复权价里，不会出现除权造成的虚假亏损。h 默认 5（配置可改），即 k+1 买入、k+6 卖出。

**它不等于账本收益**：后复权收益相当于假设「现金分红在除息时立即再投资」「配股按复权因子处理」；账本则是「分红先记应收、到账后成为现金、不自动再投资」「不参与配股」。遇到配股时两者差异最大（标签几乎不变，账本按除权价差亏损）。标签只作排序目标，因子报告的分组收益也基于它，不是可实现收益。

**标签表 `labels`**：

| 字段 | 含义 |
| --- | --- |
| `decision_date` | k |
| `instrument` | 证券 |
| `entry_date` / `exit_date` | k+1 / k+1+h（按交易日历，不是按该证券的行数） |
| `value` | 收益，小数 |
| `matured_at` | `exit_date` 当天开盘价的可用时刻（取 `exit_date` 收盘后，保守口径） |
| `valid` / `invalid_reason` | 是否有效；无效原因：`entry_suspended`、`exit_suspended`、`delisted_before_exit`、`no_price` |

**规则**：
- 进入日或退出日停牌 → 标签无效，**不顺延**到下一个有价格的日子（顺延等于悄悄换了持有期）。
- 标签无效只影响训练和因子评价的样本，**不影响**回测里对这只证券的持仓处理。

## 切分计划

按决策日期滚动：训练窗 504 个交易日、验证窗 126 个、测试窗 63 个；每向前滚一个测试窗，训练窗随之前移（固定长度）。
同一决策日的全部证券只属于一个窗口。

**防泄漏靠时间比较，不靠跳过固定行数**：选参时点为验证窗第一个决策日的决策时点，训练样本必须满足 `matured_at <= select_asof`；最终拟合时点为测试窗第一个决策日前一交易日的决策时点，验证评分和重拟合样本都必须满足 `matured_at <= fit_asof`。这样 h 变了、中间有长假，边界都自动正确。

**切分计划表 `split_plan`**：每行一个窗口，字段 `split_id`、`train_start/end`、`valid_start/end`、`test_start/end`、
`select_asof`（验证窗第一个决策日的决策时点）、`fit_asof`（测试窗开始前一交易日的决策时点）。保存在实验目录，所有模块读同一份。

**最终留出**：数据审计完成后，指定最后一段（默认最近 252 个交易日）为最终留出区间，写进配置冻结，不参与因子挑选、参数选择和组合规则选择。
用户反复看过留出区间的结果后，这段区间在报告里降级为「开发区间」。

## 训练视图与推理视图

借鉴 qlib 的做法，数据集分两种视图：

| | 训练视图 | 推理视图 |
| --- | --- | --- |
| 行 | 先在当天全部候选上预处理，再保留标签有效且满足成熟时点的样本 | 当天全部候选，不看标签 |
| 预处理 | 先横截面处理；有参数处理器只在允许的拟合窗拟合 | 同一套横截面处理与已拟合处理器 |
| 用途 | 拟合模型 | 生成测试窗预测 |

**第一版预处理器**（按顺序）：
1. 横截面去极值：每天按中位数 ± 5 倍绝对中位差截断（不需要拟合）；
2. 横截面标准化：每天减均值除标准差（不需要拟合）；
3. 缺失填补：填 0——**只在标准化之后**做，此时 0 等于当天截面均值；同时为每个因子保留「是否缺失」的信息不进入模型（第一版不加缺失指示列）。

第一版的处理器都不需要在训练集上拟合参数，天然没有跨期泄漏；有参数的处理器（如按训练集分位数截断）以后加时，只在训练窗拟合。

## 测试要点

- h = 5：k 日决策，标签端点是 k+1 与 k+6 的开盘价（用合成日历、中间插入长假验证）。
- 训练窗最后几天的样本若 `matured_at` 晚于验证窗开始，必须被排除。
- 退出日停牌的标签为无效，而不是取下一天价格。
- 修改未来某天的价格：过去的因子不变，只有依赖那天价格的标签改变。
- 同一决策日的证券不会被拆到两个窗口。
- 修改未来的标签有效性或停牌状态，历史横截面预处理结果不变。
- 配股期间：复权标签与不参与配股的账本持有收益之差与手算一致。
