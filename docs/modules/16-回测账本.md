# 模块：回测账本（ledger）

## 职责与定位

按 A 股规则逐日模拟：接收订单意图 → 检查能否成交 → 成交 → 更新现金、持仓、应收分红 → 估值 → 勾稽。
**全项目只有这一套资金账**，所有组合结果都从它出来。自己实现，不用 PyBroker（理由见 `../02-决策记录.md` 第 1 条）。

不做：选股、定权重、训练模型、联网取数。输入全部来自冻结的订单意图和数据快照。

## 输入

| 输入 | 内容 |
| --- | --- |
| 订单意图 | 组合模块产出，见 `15-组合构建.md` |
| 日线（原始价） | 开盘价、前收盘价、停牌标记、成交额 |
| 公司行动 | 现金分红（每股税前金额、除息日、到账日）、送股/转增比例、配股、吸收合并换股比例 |
| 执行规则集 | 见下文「执行规则集」 |
| 账本配置 | 初始资金、滑点、参与度上限、开盘资金口径等 |

## 每个交易日的事件顺序（固定）

1. **盘前公司行动**：对当天是除权除息日的持仓——现金分红记入应收分红（到账日, 金额）；送股/转增按比例增加股数（新增股数当天即可卖，
   与原持仓的可卖属性一致）；配股按「不参与认购」处理（股数不变，除权价下跌是真实损失）。对当天是到账日的应收分红，转入可用现金。
2. **解冻**：昨天买入的股数今天变为可卖（T+1）。
3. **读订单**：只读前一决策时点生成的订单意图。
4. **逐笔检查与撮合**（先卖后买，同方向按订单编号顺序）：
   - 停牌 → 拒单 `suspended`；
   - 开盘价无效（缺失或非正）→ 拒单 `no_open_price`；
   - 买单：开盘价达到涨停价 → 拒单 `limit_up`；卖单：开盘价达到跌停价 → 拒单 `limit_down`；
   - 卖单股数超过可卖股数 → 缩减到可卖股数，余量拒 `not_sellable`；
   - 参与度：单笔成交额不超过「决策日之前 20 个交易日平均成交额」的 5%，超出部分拒 `participation`（**不用当天成交量**）；
   - 买单资金：只用本事件之前的可用现金（`preopen_cash_only`，同一开盘时刻的卖出回款不能用于同时刻买入）；资金不足按买入单位缩量，仍不足则拒 `cash`；
   - 成交价 = 开盘价 ×（1 ± 滑点），买入加、卖出减，再按最小报价单位 0.01 元取整（买入向上、卖出向下）。
5. **记费用**：佣金（有最低收费，一笔订单只收一次最低额）、印花税（仅卖出）、过户费；税率按成交日期查执行规则集。
6. **更新现金与持仓**：买入股数计入总股数，但记为今日不可卖。
7. **撤单**：当天没成交的剩余数量全部撤销（订单只在这一个事件有效）。
8. **收盘估值**：持仓按收盘价（原始价）估值；停牌持仓用最近有效收盘价，并标 `stale_price`。
9. **勾稽**：检查恒等式，写入当日净值。

## 执行规则集（rule profile）

一张按「市场、板块、证券状态、生效起止日期」存放的规则表，放在 `configs/rule_profiles/`，每条规则带来源链接。**回测覆盖的区间里任何一天查不到规则就报错，不套用默认值。**

| 规则 | 第一版覆盖范围与取值 | 状态 |
| --- | --- | --- |
| 买入单位 | 沪深主板 100 股整数倍；卖出不足 100 股的零股可一次卖出 | 待按交易所规则逐条核实后标「已核实」 |
| 涨跌幅 | 主板 10%；主板 ST 5%；新股上市首日等例外按规则表单独列 | 同上；**上交所 2026 年修订规则（2026-07-06 起施行）对主板风险警示股的调整必须核实后入表** |
| 最小报价单位 | 0.01 元 | 同上 |
| 印花税（卖出） | 2008-09-19 起卖出单边 0.1%，2023-08-28 起 0.05%；2008-09-19 之前为双边征收、税率多次调整 | 同上，2006–2008 段的税率与起止日需对照财政部公告 |
| 过户费 | 按成交金额的一定比例，沪深统一后数次下调 | 同上 |
| 佣金 | 研究假设：万分之 2.5，最低 5 元 | 你的实际费率确定后替换；报告里写「研究假设」 |

涨跌停价 = 前收盘价 ×（1 ± 涨跌幅），四舍五入到 0.01 元。前收盘价取数据源给出的「前收盘」（除权日已是除权参考价）。

未启用的板块（创业板、科创板、北交所）规则不进第一版；启用某个板块 = 把它的规则补进规则集 + 通过本文件的测试用例。

## 持仓结构（借鉴 rqalpha 的股票持仓）

```
position: 总股数 qty, 今日买入不可卖 qty_today, 可卖 = qty - qty_today, 成本, 最近有效价, 是否过期价
dividend_receivable: [(到账日, 金额), ...]
```

## 恒等式与数值精度

每个交易日必须满足：

```
净值 = 可用现金 + 持仓市值 + 应收分红 − 应付费用
```

（日频第一版不存在冻结现金和应付费用，两项恒为 0，字段保留。）
金额用 Python `float` 计算、每笔成交后四舍五入到 0.01 元；恒等式容差 0.01 元。账本出现负现金、负持仓、卖出超过可卖股数，立即抛错并定位到日期、证券、订单。

## 无法处理的情况（阻断而不是猜）

| 情况 | 正式评价 | 探索模式 |
| --- | --- | --- |
| 持仓遇到吸收合并但换股比例表里没有 | 阻断 | 按最后价格估值继续，标出受影响持仓与日期 |
| 持仓证券退市（退市整理期结束） | 阻断 | 同上 |
| 持仓长期停牌超过 60 个交易日 | 继续，但报告列出 | 同上 |
| 除权除息日在公司行动表里缺失（由复权因子反推发现不一致） | 阻断 | 同上 |
| 回测区间结束 | 不自动清仓，按收盘价估值 | 同左 |

## 输出表

`orders`（补全状态：`filled` / `partially_filled` / `rejected` / `cancelled`，以及 `qty_filled`、`reject_reason`），
`fills`（`fill_id`、`order_id`、`date`、`qty`、`ref_price`、`fill_price`、`commission`、`stamp_tax`、`transfer_fee`），
`positions`（每日每只：`qty`、`qty_sellable`、`close`、`market_value`、`stale_price`），
`cash_events`（非交易现金变动：分红应收、分红到账，带关联的公司行动编号），
`equity`（每日：`cash`、`market_value`、`receivable`、`equity`、`daily_return`、`turnover`）。

## 测试用例（全部用合成数据，手算预期值）

1. 决策日收盘生成信号 → 最早下一交易日开盘成交，不会同日收盘成交。
2. 当日买入的股票当日卖单被拒 `not_sellable`，次日可卖。
3. 停牌拒单；开盘即涨停的买单拒单、开盘即跌停的卖单拒单。
4. 跳空高开导致资金不足：按 100 股缩量；不足 100 股拒单；现金永不为负。
5. 同一开盘时刻卖出 A、买入 B：买 B 只能用卖 A 之前的现金。
6. 现金分红：100 股 × 10 元，每股派 1 元，除息后价格 9 元 → 除息日净值 1000 元（900 市值 + 100 应收）；到账日应收转现金，净值不变、不重复计收益。
7. 10 送 10：100 股 × 10 元 → 200 股 × 5 元，净值不变。
8. 配股不参与：股数不变、除权价下跌，净值下降额等于除权价差 × 股数。
9. 最低佣金：成交额 1 万元、费率万分之 2.5 时佣金按最低 5 元收；一笔订单只成交一次，最低佣金只收一次。
10. 价格不变的买入再卖出：净值损失恰好等于双边费用 + 滑点。
11. 持仓证券退市：正式模式状态为阻断，持仓不从账本里消失。
12. 区间结束不自动清仓。
13. 印花税跨 2023-08-28：同样的卖单，前一天 0.1%、当天 0.05%。
14. 每日恒等式在全部用例中成立。

至少一个用例的全部现金流由人工在表格里独立算出，与账本逐笔比对。
