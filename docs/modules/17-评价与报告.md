# 模块：评价与报告（evaluation）

## 职责

对因子、模型、组合三层结果计算统一口径的指标，生成成对比较和报告数据。**只读已保存的结果，不重新成交、不重新训练。**
指标全部自己实现（几百行），全项目一套口径；alphalens、empyrical、quantstats 只用于开发时对照核对。

## 一、因子层

输入：因子长表、标签表、股票池。按决策日计算，汇总时**每天等权**（不让证券多的日子权重更大）。

| 指标 | 定义 |
| --- | --- |
| 覆盖率 | 当天候选中因子非缺失的比例；按年、按板块列出 |
| IC（皮尔逊） | 当天因子值与标签的皮尔逊相关 |
| 秩 IC（斯皮尔曼） | 当天因子排名与标签排名的相关；报告里与 IC 分开命名 |
| IC 均值 / 标准差 / 正比例 | 对每日序列统计；另给按年分段的结果 |
| 分组收益 | 每天按因子分 5 组，各组标签均值（基于复权标签，不是可实现收益）；并列值多到分不满 5 组时减少组数并记录实际组数，不随机打散 |
| 多空差 | 第 5 组减第 1 组，**只作诊断**，本项目不做空 |
| 分组换手 | 相邻调仓日同一组成员的变化比例 |
| 排名自相关 | 相邻决策日因子排名的相关，衡量信号稳定性 |
| 与已有因子相似度 | 开发区间内每日秩相关的均值 |

有效证券少于 30 只、因子或标签为常数的日子，当天指标为缺失并记原因。
持有期 h > 1 时每日标签相互重叠：**不把 h 日收益按天连乘成净值**，净值只来自账本。

**置信区间**：按连续日期块（块长 = h 的 4 倍，至少 20 天）重抽样 1000 次，给 IC 均值的 95% 区间（借鉴 PyBroker 的 bootstrap，改为块抽样）。
不用 `IC均值 / IC标准差 × √252` 直接下显著性结论。

## 二、模型层

同一切分、同一样本下，模型与两个基线（单因子、等权合成）逐测试窗比较：秩 IC、前 20 名的平均标签收益、分窗口胜负次数。
报告成对差值及其块抽样置信区间。特征重要性按测试窗分别列出。

## 三、组合层

输入：账本的 `equity`、`fills`、`orders`、`positions`。

| 指标 | 定义 |
| --- | --- |
| 日收益 | 相邻交易日净值之比减 1；期初净值 E₀ 为第一天开盘前的初始资金，第一天的交易费用计入第一天收益 |
| 累计收益 | 期末净值 / 期初净值 − 1 |
| 年化收益 | (E_T / E₀)^(A / T) − 1，T 为收益天数；年化系数 A = 242 是配置参数，报告里显示 |
| 年化波动 | 日收益标准差（ddof = 1）× √A |
| 夏普 | mean(r − rf_d) / std(r − rf_d, ddof = 1) × √A，rf 为年化无风险利率（默认 0），rf_d = (1 + rf)^(1/A) − 1；样本少于 20 天或标准差为 0 时不可定义 |
| 最大回撤 | 净值相对历史最高点的最大跌幅，附起止日期 |
| 主动日收益 | `a_t = r_t - b_t`；基准缺失日不删除策略收益，只排除主动指标并报告缺失天数 |
| 信息比率 | mean(a) / std(a, ddof = 1) × √A |
| 年化收益率差 | 策略年化收益 − 基准年化收益；与「主动收益的年化」是不同指标，分开命名 |
| 相对净值 | (Eₜ / E₀) / (Bₜ / B₀)，只作图示，不参与年化计算 |
| 换手 | 当日买卖成交额之和 / 前一日净值（双边口径）；半换手另列 |
| 费用 | 佣金、印花税、过户费分项合计，及占期初资金的比例 |
| 成交情况 | 订单数、成交率、按拒单原因分类的数量 |
| 现金占比 | 每日现金 / 净值的均值与分布 |
| 持仓集中度 | 每日最大单只权重、前 5 只权重和 |

零波动、样本少于 20 天、净值非正时，相关指标为「不可定义」，不以 0 或无穷大参与排序。

**基准**：默认沪深 300 价格指数（`000300.SH`），报告明确写「价格指数，不含分红」；再加一个同股票池、同调仓节奏的等权组合基线（跑同一套账本）。
基准缺日期时不删策略的日子，改为缩小共同评价区间并写明原因。

**成本情景**：同一份预测和组合配置在「研究假设费率」「费率加倍」「滑点加倍」下各自完整重跑逐日循环，列表对比；`fixed_order_replay` 只作为诊断项。

## 报告首页固定内容

数据快照编号与实际区间、股票池规则、标签定义、信号与成交时点、费用与滑点、执行近似的说明（「日频开盘参考价近似」及所用资金规则）、「收益已扣交易费用，未扣个人股息红利所得税」、证据级别、缺失与未解决事项。
报告数据以 JSON 和 Parquet 存在实验目录，前端直接读取渲染；不单独生成冗长的 HTML 或 Markdown。

## 测试要点

- 手工构造 3 天 × 5 只证券的因子与标签，IC、秩 IC、分组收益与手算一致。
- 并列值分组：10 只证券中 8 只因子值相同时，实际组数少于 5 且被记录。
- 全现金、无成交、零波动时指标输出「不可定义」而非报错。
- 基准缺一天：策略日收益完整保留，主动指标排除该日并记录缺失天数。
