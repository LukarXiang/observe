# 模块：因子与表达式（factors）

## 职责

按因子定义，在指定数据快照和证券范围上计算因子值。

不做：下载数据、训练模型、决定持仓、计算标签。

## 因子定义

因子有两种写法，都要在注册表里登记：

- **表达式因子**：用白名单算子写的一行公式，例如 `ts_mean(ret, 20) / ts_std(ret, 20)`，适合绝大多数量价因子；
- **函数因子**：一个普通 Python 函数，用于表达式写不出来的计算（如分钟聚合特征）。

每个因子登记以下字段：

| 字段 | 含义 |
| --- | --- |
| `name` / `version` | 名字和版本号；公式改了就升版本 |
| `expr` 或 `func` | 公式字符串，或函数的导入路径 |
| `fields` | 依赖的基础字段，如 `close_adj`、`amount` |
| `lookback` | 需要回看的交易日数（表达式因子由解析器自动推出，函数因子手写） |
| `min_obs` | 回看窗口内最少有效观测数，不足则输出缺失 |
| `window_safe` | 输出是否与复权方式无关（收益率、比值是；价格水平不是）；仅作说明，不限制时间序列算子嵌套 |
| `freq` | `1d` 或 `intraday`（分钟聚合后按日输出） |
| `desc` | 一句话说明经济含义 |

## 基础字段

因子只能引用下列基础字段（由数据层提供，已对齐交易日历）：

`open_adj`、`high_adj`、`low_adj`、`close_adj`（后复权价）、`ret`（按后复权收盘价算的日收益）、`volume`（股）、`amount`（元）、
`turnover`（换手率，小数）、`is_trading`（当天是否交易）。估值字段 `pe_ttm`、`pb_mrq` 已于 2026-10-03 开放，规则与来源见下文。

**为什么用后复权价**：后复权价的历史值不会因为以后的分红而改变，因此今天算出的历史因子与当年算出的一致；比值类因子不受复权基准影响。

## 算子集（第一版）

| 类 | 算子 |
| --- | --- |
| 时间序列（按单只证券沿交易日） | `ts_delay` `ts_delta` `ts_mean` `ts_std` `ts_sum` `ts_min` `ts_max` `ts_rank` `ts_corr` `ts_cov` `ts_slope` `ts_decay_linear` |
| 横截面（按同一决策日的候选证券） | `cs_rank` `cs_zscore` `cs_demean` `cs_winsorize` |
| 算术与逻辑 | `+ - * /` `abs` `log` `sign` `max2` `min2` `where` |

规则：
- 除法分母为零或非有限值时输出缺失，不输出无穷大（借鉴 gplearn 的受保护除法思路，但返回缺失而不是 1）；
- `ts_*` 的窗口按**交易日**计：停牌日在日历上占位、值为缺失，窗口内有效值少于 `min_obs` 就输出缺失，不会变成「最近 N 条有成交的记录」；
- `cs_*` 只在当天 `eligible` 的证券上计算，其他证券输出缺失。

## 表达式解析

用 Python 标准库 `ast` 把公式解析成语法树，**只放行**：白名单算子的函数调用、基础字段名、数字常量、四则运算、一元负号。
其余节点（属性访问、下标、导入、lambda 等）一律报错。解析时顺便算出 `lookback`（嵌套窗口相加）和依赖字段。不使用 `eval`。

**窗口与回看长度规则**：窗口参数必须是 1 到 500 之间的整数常量；`ts_delay`、`ts_delta` 禁止负数；违反即解析报错。回看长度按下面的规则推导：
`ts_delay(x, d)`、`ts_delta(x, d)` 为 lookback(x) + d；其他 `ts_*(x, w)` 为 lookback(x) + w − 1；双目运算与 `where` 取各参数的最大值；基础字段为 0。
例如 `ts_mean(ts_delta(close_adj, 5), 20)` 的回看长度为 5 + 20 − 1 = 24。

## 计算方式

- 输入是「交易日 × 证券」的宽表（每个字段一张），用 pandas 按列向量化计算；时间序列算子沿行滚动，横截面算子沿列运算。
- 按年分段计算时，每段向前多读 `lookback` 个交易日作为预热，只写回本段结果。**全量计算与分段计算的结果必须逐值一致**（测试覆盖）。
- 输出存为长表 `factors/<factor>@<version>/<year>.parquet`，字段：`date`、`instrument`、`value`。

## 缓存

缓存键 = 因子定义指纹 + 数据快照编号 + 证券范围指纹。任一变化都重算，不因「文件存在」就复用。

2026-10-01 已接入研究流水线：每个因子单独缓存，键另含候选与交易日历、相关代码和依赖版本。修改单个公式且预热与候选边界不变时，其余因子直接复用；修改导致候选区间变化时按新的上游指纹失效。命中前校验产物哈希，复制独立副本到实验的 `factor_parts/`，最终合并成 `factors.parquet`；详见 `../07-后端研究框架逻辑.md`。

## 分钟聚合特征（阶段四，只覆盖分钟股票池、2022 年以后）

实现在 `factors/intraday.py`。由 5 分钟线（`bars_5m`，外部 1 分钟文件合成，见决策 20）按「证券 × 交易日」算出 7 个**日频字段**，
可像 `close_adj` 一样写进因子表达式（`ts_mean(rv_5m, 20)`）；因子集里只要用到它们，研究配置就必须 `minute_pool: true`。

| 字段 | 定义 | 所需时间段 |
| --- | --- | --- |
| `rv_5m` | 日内已实现波动 = √Σ r²，r 为 5 分钟对数收益 | 全天至少 44 根 |
| `rskew_5m` | 已实现偏度 = √N · Σ r³ / (Σ r²)^1.5 | 同上；全天价格不变时缺失 |
| `rsj_5m` | 相对符号跳跃 = (上行半方差 − 下行半方差) / 总方差，取值 −1..1；与「上行 / 下行波动之比」同序，但有界 | 同上 |
| `open30_ret` | 开盘 30 分钟收益 = 10:00 收盘价 / 当日开盘价 − 1 | 09:35–10:00 的 6 根全在 |
| `tail30_ret` | 尾盘 30 分钟收益 = 15:00 收盘价 / 14:35 那根开盘价 − 1 | 14:35–15:00 的 6 根全在 |
| `tail_amount_share` | 14:35–15:00 成交额 / 全天成交额 | 尾盘 6 根全在，且全天至少 44 根 |
| `vwap_dev` | 15:00 收盘价 / 全天成交均价（总成交额 / 总成交量）− 1 | 全天至少 44 根、收盘那根在、成交量大于 0 |

规则：
- 5 分钟收益**不跨午休、不跨交易日**：每个时段（上午、下午）的第一根用 ln(收盘 / 开盘)，其余用相邻两根收盘价之比；缺根则涉及的收益缺失，已实现波动按有效收益个数放大到 48 根；
- 价格只在当天内相除，与复权无关，直接用原始价；9:25 集合竞价并入第一根 K 线（与 BaoStock 口径一致）；
- **完整性按特征所需的时间段判断**，不足时该特征当天缺失、其他特征不受影响；缺失原因（不足 44 根 / 开盘窗口不全 / 尾盘窗口不全 / 全天价格不变）在 `intraday_coverage.json` 里按年计数；
- 当日特征只用当日分钟线，决策时点是收盘后，没有前视；测试覆盖「改动某日及以后的分钟线，之前的预测逐值不变」。

**覆盖与限制**：只有当年分钟股票池内的证券有值；外部分钟文件不含退市证券，这些证券的分钟特征缺失，在横截面预处理后按 0 处理，实验限制里标「受限样本：缺退市证券的分钟数据」，证据级别为探索。
分钟因子集见 `configs/factor_sets/daily_intraday_v1.yaml`（基础因子逐字不变，后面追加 7 个 20 日均值因子，方向按经济含义先验固定）。
成对对照实验见决策 21 与 `docs/06-分钟特征成对实验报告.md`。

## 测试要点

- 窗口为 20 的 `ts_mean`：停牌 3 天的证券在恢复交易后第 1 天，窗口内只有 17 个有效值。
- `cs_rank` 在两只证券分数相同时名次相同（取平均名次）。
- 全量计算与按年分段计算逐值一致。
- 修改因子公式后，缓存失效并重算。
- 非白名单语法（如 `__import__('os')`、`close.values`）解析时报错。

## 借鉴出处

zipline 的预热行数与窗口安全、vnpy 与 polars_ta 的 `ts_`/`cs_` 分层、qlib Alpha158 的分组、gplearn 的受保护除法。见 `04-参考项目借鉴.md`。

## 估值字段与财报期算子（2026-10-03）

日频表达式与面板已开放 `pe_ttm`、`pb_mrq`，来源为冻结 bars_1d 的 BaoStock PE_TTM/PB_MRQ，不使用年度财务表替代日频估值。BP/EP 组件分别计算 `1/pb_mrq`、`1/pe_ttm`；分母零值和非有限值返回缺失，负值倒数仍是负数。正估值筛选属于显式策略规则，不能隐藏在因子解析器内。

财报单季、TTM、同比由 `data/financial_history.py` 的 `derive_periods` 提供，先用同一决策时点可见的数据选择版本；TTM 为本期累计 + 上年全年 − 上年同期累计，年末直接用全年累计。缺期输出缺失，时点存量字段拒绝流量算法。派生记录保留输入来源和最大可用时刻；它们尚未作为全部财务字段的每日面板接口，后续接入须把来源、映射版本、可用性假设和输入指纹纳入特征缓存。

本轮 BP/EP 使用 `daily_valuation_v1` 冻结估值来源，平台口径等价性仍未证明。规则策略的信号缓存包含实际输入文件、实现代码、参数、来源源码与环境；财务严格模式当前没有可放行的历史版本。验证范围和首批报告见[执行记录](../tasks/2026-10-03-财务数据标准化与策略逐批复现-执行计划.md)。
