# 模块：模型（models）

## 职责

在切分计划的每个窗口上训练模型、在测试窗生成预测分数并落盘。模型训练与组合回测完全分开：**换选股规则不重新训练。**

## 模型清单（第一版）

每个注册因子必须声明 `direction` 为 `+1` 或 `-1` 及一句经济含义；方向在注册时先验固定，不得依据任何回测结果修改。每个训练窗计算因子每日秩相关均值，相关大于 0.9 的一对只保留注册表中靠前者，并记录被淘汰因子和原因。

| 名称 | 说明 | 用途 |
| --- | --- | --- |
| `single_factor` | 直接用某一个因子的横截面排名当分数 | 基线：不用模型能做到什么程度 |
| `equal_blend` | 全部因子横截面标准化后等权相加 | 基线：最简单的多因子 |
| `ridge` | scikit-learn `Ridge` | 线性模型 |
| `lgbm` | LightGBM 回归 | 非线性模型 |

复杂模型必须和两个基线放在同一张表里比较，赢不了基线就不算有增量。

## 统一接口

四个模型都实现同样四个方法，不引入更多抽象：

```python
fit(X, y, w, X_valid = None, y_valid = None)
predict(X) -> ndarray
save(path) / load(path)
```

`save` 同时写一份说明：特征名与顺序、训练窗日期、样本数、标签版本、随机种子、线程数、依赖版本。
`predict` 时特征名或顺序与保存时不一致直接报错，**不静默补列**。

## 训练规则

- **样本权重**：每个决策日总权重相同，同一天的证券平分（避免证券多的日子主导拟合）。配置可改为逐行等权，但同一组对比实验里必须一致。
- **LightGBM 早停**只看验证窗；最终留出区间永远不参与选迭代次数。
- **参数**：第一版每个模型最多试 12 组参数，全部结果都保存，不只存最好的。
- **重拟合**：参数在验证窗选定后，用「训练窗 + 验证窗」中已成熟的样本重新拟合一次再预测测试窗，并在记录里写明做了重拟合。
- 随机种子、线程数固定写进记录；LightGBM 设 `deterministic = true`。

## 预测表 `predictions`

| 字段 | 含义 |
| --- | --- |
| `run_id` / `model_id` | 实验与模型编号（多模型、多种子用不同 `model_id`） |
| `decision_date` / `instrument` / `score` | 预测分数 |
| `split_id` / `fit_asof` | 所属测试窗与模拟拟合时点 |
| `generated_at` | 程序实际运行时间 |
| `evidence_level` | 探索 / 开发区间样本外 / 最终留出样本外 |

同一实验、同一模型里，一个「决策日 × 证券」只有一条预测。预测只覆盖测试窗，**训练窗内的拟合值不进这张表**。
预测不需要标签，标签缺失的样本照样有预测分数。

## 解释（第一版）

Ridge 输出系数；LightGBM 输出按增益计的特征重要性，并按测试窗分别统计。SHAP 不在第一版范围。解释只描述模型关系，不说因果。

## 测试要点

- 同一数据、同一种子重跑，Ridge 预测逐位一致；LightGBM 在固定线程数下一致。
- 预测阶段删掉一列特征 → 报错。
- 测试窗预测的 `fit_asof` 早于该窗第一个决策日。
- 修改测试窗标签不影响已生成的预测。
