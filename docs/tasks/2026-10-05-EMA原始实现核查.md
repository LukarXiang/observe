# 2026-10-05 EMA原始实现核查

结论：2022年55号《三进兵策略（变形版）》当前可以证明EMA接口、查询日期和动态复权基准，但不能证明聚宽服务端EMA的实际取数长度、初始化种子或停牌处理。严格本地复现应保持依赖阻断；未经另行确认，不能用TA-Lib默认EMA或自行规定预热长度替代。

本批仅作研究，未安装软件、未修改生产代码、未产生回测。新证据位于`data/staging/strategies-batch11/20261005-ema-evidence/`，创建目录和文件均拒绝覆盖。旧第七批官方缓存及原始策略只读并已再次核对字节。

## 来源实际调用

完整来源为`repo/量化策略源代码/2022年度精选策略/55.【策略研发】三进兵策略（变形版）.txt`，SHA256：`2ecc7295bec6f264228985e5f08a1dac2f5621e51ff3ecd0234473a4cea9b507`。原文标注聚宽文章`https://www.joinquant.com/post/16385`。原文件复制到证据目录`source55.bin`，保留原行尾与所有内容。

初始化采用EMA周期2、25、60，开启`use_real_price=True`，开盘运行。`trade_func`用交易日历取得昨日和前日，`get_ema`调用：

```python
ema = EMA(stock, check_date=end_dt, timeperiod=ma_value)
return ema[stock]
```

调用没有显式指定`unit/include_now/fq_ref_date`。买入是昨日EMA2严格高于EMA25、前日EMA2严格低于EMA25、昨日EMA25严格高于EMA60；卖出是反向短中线交叉，同时仍要求昨日EMA25严格高于EMA60。源码先卖后买，原池8只、5持仓槽，每次预算`available_cash / (剩余槽位 * 1.5)`。这些条件可以直接审查，但指标值如何计算不能从策略自身推出。

源码另有`get_ma`，显式`get_price(count=ma_value+10, skip_paused=False, fq='pre')`后求末尾均值；此函数没有被买卖信号调用。`is_loss`也没有被交易路径调用。不能把这些辅助函数的窗口和停牌设置移植为EMA事实，或添加原文未调用的止损。

## 官方证据

先读取旧官方缓存`data/staging/strategies-batch7/20261005-rsi-slots/joinquant-api-response.json`，原缓存SHA256：`f375859fb15b1869942e412e220162e891f1031ecffcf612c2bf950eb280276d`。它介绍`jqlib.technical_analysis`并链接[技术分析指标文档](https://www.joinquant.com/help/api/help?name=technicalanalysis)。旧缓存没有EMA实现；其中`get_price/get_bars`的停牌语义不能证明EMA内部调用其中哪个接口。

新取得第一方原始JSON：`https://www.joinquant.com/help/api/getContent?name=technicalanalysis`，返回`code=00000`，241,962字节，SHA256：`46a0421b4f6eca7e8acfdb94de04daab1a14d5fa29bccaf517df1f50e61c1137`。原响应`technicalanalysis.bin`及提取文本`technicalanalysis.txt`均保留。

| 核查项 | 官方文档明确内容 | 本来源含义与限制 |
| --- | --- | --- |
| EMA接口 | `EMA(security_list, check_date, timeperiod=30, unit='1d', include_now=True, fq_ref_date=None)` | 本来源显式覆盖timeperiod为2/25/60，其他用默认 |
| 查询截止 | 日期或`datetime.date`形式check_date返回当天收盘后指标；有时间的datetime按时间点 | 原调用查昨日/前日，开盘时不读取当天收盘 |
| 周期 | unit默认1d，timeperiod描述统计周期数 | 不是“只取N行”的证明 |
| 包含周期 | include_now默认True | 说明包含查询周期，不证明停牌是否生成填充行 |
| 复权 | 明确fq_ref_date时按其基准复权；默认None且回测开启动态复权时，基准为“策略逻辑时间” | 本来源两次历史查询在同一当日开盘回调内，不能把各自check_date擅自改为复权基准 |
| 其他环境 | 研究及jqdatasdk默认前复权；官网库与本地SDK使用入口不同 | 不能将本地SDK默认取数直接声称为原平台回测语义 |
| 跨平台差异 | 文档明确复权数据、算法、回溯技术指标取数量均可能导致差异 | 不能用“都叫EMA”证明默认TA-Lib等价 |

## 可实现边界

可以按源码固定池、严格交叉、原费用和现金槽位进行框架设计，也可以明确实现某个独立EMA实验版本，但后者需要重要规则确认并标为近似研究。当前证据不能决定以下实现选择：

- 每次EMA取完整上市历史、固定数量历史或按周期取倍数窗口；两次历史查询是否独立重算。
- 首价种子、前N项均值种子、adjust权重法，以及缺失/不足历史的返回方式。
- 停牌行剔除、前值填充或缺失阻断，以及停牌窗口的统计周期如何计数。
- 聚宽原年代jqlib的具体版本、后端实现及与当前接口的等价性。

本次没有获取平台登录凭据或运行官方服务端数值样本，不能以当前本地TA-Lib结果比较替代这四项证明。后续起点是官方jqlib源码或平台可审计的EMA取数/数值样本；取得前将55号登记“待指标实现证据”，继续其他来源。
