## 使用入口

```bash
# 已审查的规则策略配置；快照须存在于本机
~/envs/quant/.venv/bin/observe --root data strategy run --config configs/strategies/bp_component_v1.yaml --snapshot "$STRATEGY_SNAPSHOT"

# 本地声明式规格；省略 snapshot 时冻结当前已发布状态
~/envs/quant/.venv/bin/observe --root data strategy validate
~/envs/quant/.venv/bin/observe --root data strategy run y2024b-081 --snapshot "$STRATEGY_SNAPSHOT" --start 2024-04-01 --end 2024-06-28
~/envs/quant/.venv/bin/observe --root data strategy report

# 两种新实验通过同一复现入口读取冻结来源，不联网
~/envs/quant/.venv/bin/observe --root data reproduce "$STRATEGY_RUN"
```

`--config` 与声明式位置参数不能混用。声明式目前不支持任务队列和阶段缓存选项；多规格运行的 `--output` 会被拒绝。远程 `strategy catalog` 输出经审查的来源目录至 `data/catalog/strategies/`；本地 `scripts/build_strategy_catalog.py` 保留 `strategies/catalog.csv` 和原 `y2024b-081` 编号，两种编号不是同一身份。

财务文件路径、重导入、查询和字段限制见 [财务数据导入与使用](../08-财务数据导入与使用.md)。
